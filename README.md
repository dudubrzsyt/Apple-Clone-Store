# 🍎 Apple Clone Store

Um clone da loja oficial da Apple, desenvolvido para fins de estudo e prática de front-end.  
O projeto replica o design minimalista e elegante da Apple, utilizando **React + Vite** e estilização moderna.

---

## 🚀 Tecnologias utilizadas

- [React](https://react.dev/) – Biblioteca para construção de interfaces
- [Vite](https://vitejs.dev/) – Bundler rápido para desenvolvimento
- [TypeScript](https://www.typescriptlang.org/) – Tipagem estática
- [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS) – Estilização customizada
- [ESLint](https://eslint.org/) – Padronização de código

## ⚙️ Instalação e execução

Clone o repositório:

```bash
git clone https://github.com/dudubrzsyt/Apple-Clone-Store.git
cd Apple-Clone-Store/apple.com

Instale as dependências:

npm install

Execute em modo desenvolvimento:
npm run dev


Build para produção:
npm run build



🌐 Deploy
O projeto está hospedado na Vercel.
Cada novo commit enviado para a branch main no GitHub gera automaticamente um novo deploy.

🎨 Features
- Header centralizado com tipografia San Francisco, igual ao site oficial da Apple
- Layout responsivo e minimalista
- Navegação entre páginas (Home, Buscar, Comprar, Sacola, Contato)
- Estilo clean inspirado no design da Apple
