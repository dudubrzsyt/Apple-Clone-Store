## 📌 Sobre o Projeto | About the Project
🇧🇷 **Loja de Clone Apple** é um projeto front-end que recria a experiência de navegação e compra no site oficial da Apple.  
🇺🇸 **Apple Clone Store** is a front-end project that recreates the browsing and shopping experience of Apple's official website.

---

## ✨ Funcionalidades | Features
- Navegação responsiva com **Header estilo Apple**  
- Página de compra com seleção de **cores e armazenamento**  
- Galeria de imagens rolável dos produtos  
- Submenu de modelos com preços e redirecionamento  
- Ícones de **sacola** e **lupa** para compras e busca

## ⚙️ Instalação | Installation
Clone o repositório e instale as dependências:

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/apple-clone-store.git

# Entre na pasta
cd apple-clone-store

# Instale as dependências
npm install

▶️ Uso | Usage
Execute o servidor de desenvolvimento:
npm run dev


Abra no navegador:
http://localhost:5173 (localhost in Bing)

📂 Estrutura de Páginas | Pages Structure
- / → Página inicial (Loja)
- /comprar → Página de compra (ComprarPage.tsx)
- /iphone17pro → Página iPhone 17 Pro Max
- /iphone17 → Página iPhone 17 Pro
- /iphone16pro → Página iPhone 16 Pro Max
- /iphone16 → Página iPhone 16 Pro
